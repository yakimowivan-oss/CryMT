**CryMT v14: GOG version, English, FPS of the presets**

## Русский

**Новое**
- **Работает с c1-launcher v7 из GOG.** Вылеты 64-битной игры из-за памяти выше 4 ГБ CryMT теперь исправляет сам.
  - Проверено на демо CPU island: ванильный v7 упал 3 раза из 3, с CryMT — 0 из 9.
  - Ставить v8 больше не обязательно, но рекомендуем: в нём больше исправлений игры.
- **Лаунчер на русском и английском** (переключатель RU / EN в шапке). Язык по умолчанию — язык Windows.
- **FPS пресетов на карточках.** Мои замеры в четырёх тестах (CPU2, GPU, Village, Harbor), 2560×1440 в окне, Very High, Ryzen 7 5800X + RTX 4070 SUPER. Рядом прирост к ванили.
- **«Что нового» показывается целиком**, на языке лаунчера.

**Исправлено**
- **Видеокарты AMD и старые NVIDIA.** Без DLSS игра теперь сохраняет своё сглаживание. Раньше в режимах DLAA не было никакого сглаживания.
- **MSAA из настроек игры с CryMT выключается**: с ним не работали DLAA и GI, пропадали тени. В режиме «Ваниль» MSAA работает как обычно.

## English

**New**
- **Works with GOG's c1-launcher v7.** CryMT now fixes the 64-bit game's crashes with memory above 4 GB itself.
  - Tested on the CPU island demo: vanilla v7 crashed 3 of 3 runs, with CryMT 0 of 9.
  - v8 is no longer required but still recommended: it fixes more of the game's bugs.
- **The launcher speaks English and Russian** (RU / EN switch in the header). It defaults to the Windows language.
- **Preset FPS on the cards.** My measurements in four tests (CPU2, GPU, Village, Harbor), 2560×1440 window, Very High, Ryzen 7 5800X + RTX 4070 SUPER, with the change against vanilla.
- **"What's new" shows the whole notes**, in the launcher's language.

**Fixed**
- **AMD and older NVIDIA cards.** Without DLSS the game now keeps its own anti-aliasing. Before, DLAA modes had none at all.
- **The game's MSAA is turned off with CryMT**: DLAA and GI did not run with it and shadows went missing. Vanilla mode keeps it.
