**CryMT v17 (test): screen-space shadows, a HUD that no longer slows the game, no GPU hangs at saves**

Test build: the launcher offers it only in the **Test** channel (Updates page). It can have bugs; **Roll back** returns the previous version.

## Русский

**Новое**
- **Тени в экранном пространстве (SSS, по методу Bend Studio)** вместо прежних контактных теней (пресет «Полный»).
  - Каждый пиксель проверяет ~60 соседних пикселей в сторону солнца: тени у основания предметов и от мелких деталей стали длиннее и чище, без шума.
  - Деревья и скалы отбрасывают тени и вдали, за пределами карт теней (до 4 км).
  - Оружие отбрасывает тень на руки.
  - На панели в игре (Num/ ▸ AO): «Контактные тени» (выкл / старые / SSS), «Дальность SSS», «SSS: толщина рук и оружия».
  - Стоимость около 0,2 мс видеокарты при 2560×1440.
- **HUD больше не тормозит игру.** Главный поток не ждёт поток рендера на отрисовке интерфейса (Flash). В деревне при 5120×1440: без GI 51,6 → 81,4 FPS, с GI 45,4 → 56,8 FPS. Выключить: строка `CRYMT_SFQUEUE=0` в разделе [Env] файла CryMT.ini.
- **Новая панель CryMT в игре** (Num/): вкладки и курсор на цифровом блоке.
  - Num7/Num9 — вкладка, Num8/Num2 — строка, Num4/Num6 — значение, Num5 — по умолчанию.
  - Изменённые значения подсвечены.
  - Время суток — Num+/Num−.
- **Кэш дальних каскадов теней** включён по умолчанию (e_gsm_cache 1); переключатель — в лаунчере.

**Исправлено**
- **Зависание видеокарты и вылет при сохранениях** (автосохранения, контрольные точки, быстрое сохранение). Изображение замирало при работающем звуке (сброс драйвера видеокарты) или игра вылетала в nvwgf2umx.dll. Миниатюра сохранения записывалась в команды видеокарты из чужого потока и недопустимой копией.
- **Зависание игры при полётах в насыщенных местах** (два потока в CryPhysics). Частицы в потоке рендера больше не проверяют столкновения с объектами, с землёй — проверяют.
- **«Кипение» воксельного GI** на стоящей камере; ячейки вокселей стабильнее.

**Для диагностики.** При сбросе видеокарты CryMT пишет в CryMT\logs\mt\d3d12.txt отчёт о том, что делала видеокарта (DRED). Это стоит около 2,6% FPS; в стабильной версии будет выключено. Если игра замрёт, пришлите этот файл.

## English

**New**
- **Screen-space shadows (SSS, Bend Studio's method)** in place of the old contact shadows (the "Full" preset).
  - Each pixel checks ~60 neighbouring pixels towards the sun: shadows at the base of objects and from small details are longer and cleaner, without noise.
  - Trees and rocks cast shadows far away too, beyond the shadow maps (up to 4 km).
  - The weapon shadows the hands.
  - In-game panel (Num/ ▸ AO): "Contact shadows" (off / old / SSS), "SSS reach", "SSS: hands and weapon thickness".
  - Cost about 0.2 ms of GPU time at 2560×1440.
- **The HUD no longer slows the game.** The main thread no longer waits for the render thread at the interface's (Flash) draws. Village at 5120×1440: 51.6 → 81.4 FPS without GI, 45.4 → 56.8 FPS with GI. To turn it off: the line `CRYMT_SFQUEUE=0` in the [Env] section of CryMT.ini.
- **New in-game CryMT panel** (Num/): tabs and a numpad cursor.
  - Num7/Num9 tab, Num8/Num2 row, Num4/Num6 value, Num5 default.
  - Values that differ from their default are highlighted.
  - Time of day on Num+/Num-.
- **Far shadow cascade cache** on by default (e_gsm_cache 1); the switch is in the launcher.

**Fixed**
- **GPU hang and crash at saves** (autosaves, checkpoints, quicksave). The picture froze with the sound still playing (a graphics driver reset), or the game crashed in nvwgf2umx.dll. The save thumbnail was written into the GPU command list from another thread and with an invalid copy.
- **Game hang when flying through dense places** (two threads in CryPhysics). Particles on the render thread no longer test collisions with objects; terrain is still tested.
- **Voxel GI "boiling"** on a still camera; voxel cells are steadier.

**Diagnostics.** On a GPU reset CryMT writes a report of what the GPU was doing (DRED) to CryMT\logs\mt\d3d12.txt. It costs about 2.6% FPS and will be off in the stable version. If the game freezes, please send that file.
